## Checklists par Plateforme

### Checklist YouTube Shorts

**Avant Publication :**
- [ ] Titre optimisé (60 caractères max, hook + keyword)
- [ ] Description complète (200-300 mots)
- [ ] Lien vers vidéo longue dans description
- [ ] 3-5 hashtags pertinents
- [ ] Thumbnail accrocheur (même si court)
- [ ] Sous-titres vérifiés
- [ ] End screen vers vidéo longue
- [ ] Cards configurées

**Après Publication :**
- [ ] Répondre aux 5 premiers commentaires
- [ ] Partager en Community post
- [ ] Analyser analytics (premières 24h)

### Checklist Instagram Reels

**Avant Publication :**
- [ ] Caption engageante (hook dans première ligne)
- [ ] 10-15 hashtags (mix niche + trending)
- [ ] Text overlay stylisé (si pertinent)
- [ ] Musique tendance Instagram
- [ ] Cover photo accrocheuse
- [ ] Lien bio vers YouTube (vérifier)
- [ ] Mention YouTube dans caption

**Après Publication :**
- [ ] Répondre aux 10 premiers commentaires (dans les 12h)
- [ ] Partager en Story avec swipe-up
- [ ] Pin comment avec lien YouTube
- [ ] Analyser insights (premières 6h)

### Checklist TikTok

**Avant Publication :**
- [ ] Caption ultra-courte (hook fort)
- [ ] Hook visuel dans les 3 premières secondes
- [ ] Musique trending TikTok
- [ ] 3-5 hashtags (mix niche + #fyp)
- [ ] Lien bio vers YouTube (vérifier)
- [ ] Mention YouTube dans caption

**Après Publication :**
- [ ] Répondre aux commentaires rapidement (dans les 6h)
- [ ] Pin comment avec lien YouTube
- [ ] Duet/Stitch friendly (si pertinent)
- [ ] Analyser analytics (premières 6h cruciales)

## Calendrier de Publication Optimal

### Template Hebdomadaire

| Jour | YouTube | Instagram | TikTok | Notes |
|------|---------|-----------|--------|-------|
| Lundi | Vidéo longue (15h) | Reel (17h) | Vidéo (19h) | Lancement semaine |
| Mardi | Short (18h) | Post carrousel (11h) | Vidéo (19h) | Engagement |
| Mercredi | Short (18h) | Reel (17h) | Vidéo (19h) | Milieu semaine |
| Jeudi | Short (18h) | Story (toute la journée) | Vidéo (19h) | Engagement |
| Vendredi | Short (18h) | Reel (17h) | Vidéo (19h) | Fin semaine |
| Samedi | Short (18h) | Post carrousel (11h) | Vidéo (19h) | Week-end |
| Dimanche | Short (18h) | Reel (17h) | Vidéo (19h) | Week-end |

### Notes Importantes

- **YouTube :** Vidéo longue le lundi pour maximiser la semaine
- **Instagram :** Reels aux heures de pointe (9-11h, 17-19h)
- **TikTok :** Toujours 18h-22h pour maximiser le reach
- **Espacer :** Minimum 4h entre publications sur même plateforme

## Optimisations Avancées

### A/B Testing des Captions

**Test 1 : Longue vs Courte**
- Version A : Caption longue (200 mots)
- Version B : Caption courte (50 mots)
- Mesurer : Engagement rate, vues

**Test 2 : Avec vs Sans Emojis**
- Version A : Avec emojis
- Version B : Sans emojis
- Mesurer : Engagement rate

**Test 3 : Hashtags Niche vs Trending**
- Version A : 10 hashtags niche
- Version B : 5 niche + 5 trending
- Mesurer : Reach, nouvelles audiences

### Optimisation des Hashtags

**Stratégie Mix :**
- 40% hashtags niche (petite audience, haut engagement)
- 40% hashtags moyennement populaires (audience moyenne)
- 20% hashtags trending (grande audience, faible engagement)

**Rotation :**
- Changer 20-30% des hashtags chaque semaine
- Tester nouveaux hashtags régulièrement
- Analyser quels hashtags génèrent le plus d'engagement
