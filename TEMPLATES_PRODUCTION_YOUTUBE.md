## 9. TEMPLATE SOP (Standard Operating Procedure)

```
═══════════════════════════════════════════════════════════════
SOP : PRODUCTION VIDÉO LONGUE QUOTIDIENNE
Version : 1.0
Dernière mise à jour : ___/___/______
═══════════════════════════════════════════════════════════════

OBJECTIF
─────────────────────────────────────────────────────────────
Produire et publier 1 vidéo longue (8-12 min) par jour de 
manière efficace et reproductible.

TEMPS TOTAL ESTIMÉ : 4-5 heures

═══════════════════════════════════════════════════════════════
ÉTAPE 1 : RECHERCHE SUJET (30-45 min)
═══════════════════════════════════════════════════════════════

1.1 Vérifier calendrier éditorial
    → Si sujet prévu : passer à 1.4
    → Si pas de sujet : continuer

1.2 Rechercher tendances
    • Google Trends (niche)
    • VidIQ trending videos
    • Reddit r/[niche]
    • Twitter/X hashtags

1.3 Valider potentiel
    • Volume recherche > ______
    • Compétition < ______
    • Pertinence pour audience : oui/non

1.4 Documenter recherche
    • Ouvrir template script
    • Collecter 5+ sources
    • Noter statistiques clés
    • Identifier angle unique

✓ LIVRABLE : Sujet validé + sources collectées

═══════════════════════════════════════════════════════════════
ÉTAPE 2 : RÉDACTION SCRIPT (60-90 min)
═══════════════════════════════════════════════════════════════

2.1 Rédiger hook (5 min)
    → Tester 3 versions
    → Choisir la plus percutante

2.2 Rédiger intro (10 min)
    → Contexte
    → Promesse
    → Transition

2.3 Rédiger corps principal (45-60 min)
    → Point 1 + exemple
    → Point 2 + exemple  
    → Point 3 + exemple
    → Transitions fluides

2.4 Rédiger climax (10 min)
    → Révélation principale
    → Moment "aha"

2.5 Rédiger conclusion (5 min)
    → Récap
    → CTA
    → Teaser

2.6 Relecture et timing
    → Lire à voix haute
    → Vérifier ~150 mots/minute
    → Ajuster si nécessaire

✓ LIVRABLE : Script finalisé (~1500-2000 mots)

═══════════════════════════════════════════════════════════════
ÉTAPE 3 : VOIX-OFF (15-30 min)
═══════════════════════════════════════════════════════════════

3.1 Préparer script pour TTS
    → Corriger prononciations
    → Ajouter pauses (...)
    → Marquer emphases

3.2 Générer voix-off
    → Ouvrir ElevenLabs/Play.ht
    → Sélectionner voix : _______
    → Paramètres : Stabilité ___ / Clarté ___
    → Générer par sections

3.3 Vérifier qualité
    → Écouter intégralement
    → Régénérer sections problématiques
    → Exporter en WAV/MP3

✓ LIVRABLE : Fichier audio voix-off

═══════════════════════════════════════════════════════════════
ÉTAPE 4 : COLLECTE FOOTAGE (30-45 min)
═══════════════════════════════════════════════════════════════

4.1 Lister besoins visuels
    → Section par section du script
    → Keywords de recherche

4.2 Sources (par ordre de préférence)
    1. Storyblocks (abonnement)
    2. Pexels (gratuit)
    3. Pixabay (gratuit)
    4. Archives.org (historique)

4.3 Télécharger et organiser
    → Créer dossier projet : /Videos/[Date]-[Titre]/
    → Sous-dossiers : /Footage /Audio /Export
    → Renommer fichiers logiquement

✓ LIVRABLE : Dossier organisé avec tous les assets

═══════════════════════════════════════════════════════════════
ÉTAPE 5 : MONTAGE (90-120 min)
═══════════════════════════════════════════════════════════════

5.1 Setup projet
    → Ouvrir DaVinci/Premiere
    → Importer assets
    → Créer timeline

5.2 Montage rough cut
    → Placer voix-off
    → Sync footage grossier
    → Vérifier durée globale

5.3 Montage fine cut
    → Ajuster cuts
    → Transitions
    → Zooms/effets
    → Textes à l'écran

5.4 Audio
    → Musique background
    → Effets sonores
    → Normaliser niveaux (-6dB voix, -18dB musique)

5.5 Color grading (optionnel)
    → Appliquer LUT cohérent
    → Ajuster exposition

5.6 Export
    → H.264
    → 1080p minimum (4K si possible)
    → Bitrate : 15-20 Mbps

✓ LIVRABLE : Vidéo exportée prête à upload

═══════════════════════════════════════════════════════════════
ÉTAPE 6 : THUMBNAIL (15-20 min)
═══════════════════════════════════════════════════════════════

6.1 Ouvrir template Canva
6.2 Sélectionner image de fond
6.3 Ajouter texte (max 3 mots)
6.4 Vérifier lisibilité mobile
6.5 Exporter PNG 1280x720

✓ LIVRABLE : Thumbnail finale

═══════════════════════════════════════════════════════════════
ÉTAPE 7 : UPLOAD & SEO (20-30 min)
═══════════════════════════════════════════════════════════════

7.1 Upload vidéo (pendant : continuer SEO)
7.2 Remplir titre (template SEO)
7.3 Remplir description
7.4 Ajouter tags
7.5 Upload thumbnail
7.6 Définir catégorie
7.7 Ajouter end screens
7.8 Ajouter cards
7.9 Programmer publication
7.10 Vérifier preview

✓ LIVRABLE : Vidéo programmée

═══════════════════════════════════════════════════════════════
ÉTAPE 8 : SHORTS (60-90 min pour 6 shorts)
═══════════════════════════════════════════════════════════════

8.1 Identifier 3 moments clés de la vidéo longue
8.2 Extraire clips (30-45 sec chacun)
8.3 Ajouter texte + effets CapCut
8.4 Créer 3 shorts originaux additionnels
8.5 Export format vertical 9:16
8.6 Upload et programmer

✓ LIVRABLE : 6 Shorts programmés

═══════════════════════════════════════════════════════════════
CHECKLIST FINALE
═══════════════════════════════════════════════════════════════

[ ] Thumbnail accrocheuse
[ ] SEO optimisé
[ ] Vidéo programmée
[ ] 6 Shorts programmés
[ ] Fichiers archivés
```
