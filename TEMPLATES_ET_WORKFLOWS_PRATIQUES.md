## Template de Script Vidéo

### Structure Standard (10-15 minutes)

```
[TITRE DE LA VIDÉO]
[NICHE]
[DURÉE CIBLE: 12 minutes]

---

### HOOK (0-15 secondes)
[Question accrocheuse ou déclaration choquante]
Exemple: "Saviez-vous que 90% des gens font cette erreur qui leur coûte des milliers d'euros chaque année ?"

### INTRODUCTION (15-60 secondes)
- Présentation du problème/sujet
- Pourquoi c'est important
- Ce que le spectateur va apprendre
- Preview des points clés

Exemple:
"Bonjour et bienvenue sur [Nom de la chaîne]. Aujourd'hui, nous allons parler de [sujet]. Si vous êtes comme la plupart des gens, vous faites probablement [erreur commune]. Dans cette vidéo, je vais vous révéler [nombre] stratégies que les pros utilisent pour [résultat]. Restez jusqu'à la fin car le point numéro [X] va complètement changer votre façon de voir les choses."

### CORPS - POINT 1 (2-3 minutes)
- Titre du point
- Explication détaillée
- Exemple concret
- Transition vers le point suivant

### CORPS - POINT 2 (2-3 minutes)
[Même structure]

### CORPS - POINT 3 (2-3 minutes)
[Même structure]

### CORPS - POINT 4 (2-3 minutes)
[Même structure]

### CONCLUSION (30-60 secondes)
- Résumé des points clés
- Action immédiate à prendre
- Call-to-action
- Lien vers vidéo suivante

Exemple:
"Pour résumer, nous avons vu [point 1], [point 2], [point 3], et [point 4]. La chose la plus importante à retenir est [message clé]. Si vous mettez en pratique ne serait-ce qu'un seul de ces points dès aujourd'hui, vous verrez des résultats dans [délai]. N'oubliez pas de liker cette vidéo si elle vous a aidé, et abonnez-vous pour ne pas manquer nos prochaines vidéos sur [sujet connexe]. À bientôt !"

---

### MÉTADONNÉES
- Mots-clés principaux: [liste]
- Mots-clés secondaires: [liste]
- CTA principal: [action]
- CTA secondaire: [action]
```

## Workflow Automatisé Complet

### Workflow Quotidien (3-4 heures)

#### ÉTAPE 1 : Recherche et Script (1h)

**1.1 Recherche de sujet (15 min)**
- Utiliser Google Trends
- Analyser VidIQ/TubeBuddy pour keywords
- Vérifier la concurrence
- Choisir un angle unique

**1.2 Recherche approfondie (20 min)**
- ChatGPT/Claude : Recherche détaillée
- Sources : Articles, études, statistiques
- Points clés : 4-5 idées principales
- Exemples concrets : 2-3 par point

**1.3 Rédaction du script (25 min)**
- Utiliser le template ci-dessus
- Longueur : 1500-2000 mots
- Intégration SEO naturelle
- Vérification : Flow, clarté, engagement

#### ÉTAPE 2 : Narration AI (30 min)

**2.1 Préparation (5 min)**
- Copier le script dans ElevenLabs
- Choisir la voix (cohérente avec la chaîne)
- Réglages : Vitesse 0.95x, Stabilité 0.5

**2.2 Génération (15 min)**
- Générer par paragraphes
- Écouter et ajuster
- Pauses naturelles
- Intonation appropriée

**2.3 Export (10 min)**
- Export en WAV haute qualité
- Vérification audio
- Backup du fichier

#### ÉTAPE 3 : Montage (1h)

**3.1 Préparation (10 min)**
- Importer audio dans CapCut/Premiere
- Créer timeline
- Importer B-roll (Pexels/Pixabay)
- Importer musique (Epidemic Sound)

**3.2 Montage principal (30 min)**
- Synchroniser B-roll avec narration
- Ajouter transitions (subtiles)
- Musique de fond (volume 20-30%)
- Sous-titres automatiques (améliorer manuellement)

**3.3 Finalisation (20 min)**
- Color grading (cohérent)
- Vérification audio (niveaux)
- Ajout de cards et end screens
- Export 1080p 60fps

#### ÉTAPE 4 : Thumbnail et Métadonnées (30 min)

**4.1 Thumbnail (15 min)**
- Canva : Template réutilisable
- Éléments : Visage/objet + texte accrocheur
- Couleurs : Contrastées, lisibles
- A/B testing : Créer 2-3 variations

**4.2 Métadonnées (15 min)**
- Titre : SEO + hook (60 caractères max)
- Description : 200-300 mots avec keywords
- Tags : 10-15 tags stratégiques
- Catégorie : Appropriée
- Timestamps : Dans la description

#### ÉTAPE 5 : Formats Courts (1h)

**5.1 Extraction (20 min)**
- Identifier 6 moments clés
- Durée : 30-60 secondes chacun
- Hook fort au début
- Message clair

**5.2 Montage rapide (30 min)**
- Template CapCut pour Shorts
- Sous-titres animés
- Musique tendance
- Export format vertical (9:16)

**5.3 Optimisation (10 min)**
- Titres accrocheurs pour chaque
- Thumbnails (si nécessaire)
- Hashtags pertinents

#### ÉTAPE 6 : Upload et Distribution (30 min)

**6.1 YouTube (15 min)**
- Upload vidéo longue
- Programmer publication (heure optimale)
- Upload 6 Shorts
- Programmer sur 6 jours différents

**6.2 Réseaux sociaux (15 min)**
- Extraits pour TikTok/Instagram
- Programmer avec Buffer/Hootsuite
- Community post YouTube

## Templates de Prompts ChatGPT

### Prompt 1 : Recherche de Sujet

```
Je gère une chaîne YouTube sur [NICHE]. Je dois créer une vidéo de 12 minutes qui va générer beaucoup de vues et d'engagement.

Critères :
- Sujet actuel et recherché
- Angle unique (pas déjà traité 1000 fois)
- Potentiel viral
- Valeur ajoutée claire

Donne-moi 5 idées de sujets avec pour chaque :
1. Le titre de la vidéo
2. Pourquoi ça va marcher
3. Les 4-5 points clés à aborder
4. Les keywords SEO principaux
```

### Prompt 2 : Script Complet

```
Écris un script YouTube de 12 minutes (1500-2000 mots) sur le sujet : [SUJET]

Structure requise :
- Hook accrocheur (15 secondes)
- Introduction engageante (45 secondes)
- 4 points principaux détaillés (2-3 min chacun)
- Conclusion avec CTA (30 secondes)

Style :
- Conversationnel et engageant
- Exemples concrets
- Statistiques et faits
- Questions rhétoriques
- Transitions fluides

Intègre naturellement ces keywords : [LISTE KEYWORDS]

Le script doit être prêt pour narration AI (ponctuation claire, pauses naturelles).
```

### Prompt 3 : Optimisation SEO

```
Analyse ce titre YouTube et améliore-le pour maximiser les vues :

Titre actuel : [TITRE]

Critères d'amélioration :
- Intégrer le keyword principal : [KEYWORD]
- Ajouter un élément émotionnel (curiosité, urgence, bénéfice)
- Rester sous 60 caractères
- Être spécifique et prometteur

Donne-moi 5 variations optimisées avec explication de pourquoi chacune fonctionne.
```

### Prompt 4 : Description YouTube

```
Écris une description YouTube optimisée SEO pour cette vidéo :

Titre : [TITRE]
Durée : [DURÉE]
Sujet : [SUJET]

Structure requise :
- Première ligne : Hook + keywords (150 caractères)
- Paragraphe 1 : Résumé engageant (100 mots)
- Timestamps : [LISTE TIMESTAMPS]
- Paragraphe 2 : Informations complémentaires (50 mots)
- CTA : Abonnement + liens
- Hashtags : 3-5 pertinents

Longueur totale : 200-300 mots
Keywords à intégrer : [LISTE]
```

**Formule gagnante :**

**Exemples :**
- "Cette Erreur Vous Coûte 10 000€ Par An (Guide Complet)"
- "90% des Gens Ignorent Cette Stratégie ChatGPT"
- "Comment J'ai Gagné 50 000€ en 6 Mois (Méthode Révélée)"

### Template de Description

```

Cette vidéo va vous révéler [BÉNÉFICE PRINCIPAL]. Si vous voulez [RÉSULTAT], cette vidéo est pour vous.

📋 DANS CETTE VIDÉO :
0:00 - Introduction

- [Lien 1]

- Instagram : [@compte]
```

### Template de Tags

**Stratégie de tags :**
1. Tag principal (exact match titre)
2. Variantes du tag principal (3-4)
3. Tags de niche (3-4)
4. Tags génériques populaires (2-3)
5. Tags longue traîne (2-3)

**Exemple pour niche Finance :**
```

investir en bourse

épargne
```

## Formules de Calcul de Revenus

### Calcul Basique

```
Revenus mensuels = (Vues mensuelles × Taux de rétention × CPM) / 1000
```

**Variables :**
- Vues mensuelles : Nombre total de vues
- Taux de rétention : % de visionnage complet (généralement 30-50%)
- CPM : Coût pour mille impressions (varie par niche)

### Calcul Détaillé

```
Revenus = (Vues × Taux de clic × Taux de rétention × CPM) / 1000
         + Revenus sponsorships
         + Revenus affiliation
         + Revenus autres
```

### Calculateur Excel/Google Sheets

| Métrique | Valeur | Formule |
|----------|--------|---------|
| Vues mensuelles | 500 000 | - |
| Taux de rétention | 40% | - |
| CPM (€) | 6 | - |
| **Revenus YouTube** | **1 200€** | `=(B2*B3*B4)/1000` |
| Sponsorships | 500€ | - |
| Affiliation | 300€ | - |
| **TOTAL** | **2 000€** | `=B5+B6+B7` |

### Projections

**Formule de croissance :**
```
Vues mois N = Vues mois N-1 × (1 + Taux de croissance)
```

**Exemple :**
- Mois 1 : 50 000 vues
- Taux de croissance : 20%/mois
- Mois 2 : 50 000 × 1.20 = 60 000 vues
- Mois 3 : 60 000 × 1.20 = 72 000 vues
